## 2. 何を作ったか（`youtube_studio/`）

```
毎日 5:00（タスクスケジューラ）
  再生数の取り込み → 企画 → 台本（ローカルAI か Claude）→ VOICEVOX → 本編・ショート・サムネ → 確認待ち
人（スマホ・SOT21 から数分）
  見る → 承認（予約投稿）／理由を書いて見送り（理由は次の台本に必ず反映）
```

- 確認待ちが3本溜まったら新しく作らない（見られない動画を量産しない）
- 台本には「人が確かめる点（checks）」を必ず書かせ、承認画面に出す
- 投稿は既定で **manual**（承認画面のコピーボタン → YouTube Studio に貼る）。
  監査を通っていない API プロジェクトから投稿すると強制非公開になるため。監査後に `youtube.upload = "api"` で自動投稿
- 再生数の取り込みは `python run.py auth`（OAuth）か api_key + channel_id で動く（読み取りは監査不要）

| ファイル | 内容 |
| --- | --- |

| `studio/writer.py` | 企画と台本（Ollama / Claude `claude-opus-5-5`）。JSONを検査して1回だけ書き直させる |

## 4. 未決定のこと（→ 2026-10-15 に6で決定済み。以下は当時の記録）

### A. チャンネルの方向（提案中）

テーマ「収益を視聴者に還元する」に対し、登録者19人では当面収益がゼロなので、**収益ゼロの日から還元が成り立つ形**を提案した:

| 頻度 | 中身 | 還元するもの |
| --- | --- | --- |
| 毎日（自動） | 得する情報（期限つきキャンペーン・給付金/補助金・ポイント・値上げ前の対策） | 視聴者の節約額 |
| 月1回 | 収益報告（再生数・収益・還元額を全部公開） | 信頼・差別化 |
| 収益が出たら | 還元方法を視聴者投票で（寄付先 or 抽選プレゼント） | お金そのもの |

伝えた注意点:
- 登録・高評価・コメントを応募条件にしない（YouTube の規約違反）
- 「見るだけでお金がもらえる」はやらない（再生の水増し扱い）
- 参加費を取って抽選しない（賭博にあたるおそれ）
- 現金配布は詐欺アカウントと誤認されやすい → プレゼント・寄付の方が安全

### B. 今のチャンネルの中身

聞いていること: 動画の本数と内容 / 顔出し・声の有無 / 一番再生された動画のタイトル。
チャンネル名「アタル」が懸賞の「当たる」由来なら方向と合うが、今の内容と大きく変えると今の登録者が離れる。
