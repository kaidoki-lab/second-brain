## 2. 何を作ったか

README では「ローカルAI」が参加者として名前だけ載っていて、どこにも接続されていなかった。
そこで、手元のAI（Ollama / LM Studio）を第二の脳につなぎ、次の循環で育てる仕組みを作った。
重みの学習（ファインチューニング）はしていない。

```
話す → 学ばせる → 第二の脳へ保存 → 育てる（モデルを作り直す）→ 次の会話はもっと分かっている
```

| 段階 | 中身 |
| --- | --- |
| 話す | 役割 `local` のコンテキスト（私について・現在地・決定事項・事実）を前提に会話する。**会話の全文は保存しない** |
| 学ばせる | 会話から `DECISION / FACT / OPEN / PHASE / PROFILE` の行をAI自身に抜き出させ、人が確認してから保存する。二度保存しても件数は増えない |
| 育てる | 「私について」と進行中の企画の決定事項・事実を約3000トークンに収めてモデルに覚えさせ、Ollama の `/api/create` で `second-brain` モデルとして作り直す。成長記録（日時・件数・前回からの増分）が残る |
| Llama | 画面のボタンで Llama 3.2 3B / Llama 3.1 8B / Llama 3 ELYZA JP 8B を取得し、そのまま育てる元のモデルに設定する |

## 5. 守っている設計の約束（変えないこと）

- 会話の全文は保存しない。保存するのは人が確認した結論だけ
- AIへ全コンテキストは渡さない。役割 `local` で見せる範囲を絞る（ファイル・ハンドオフ・APIは見せない）
- 依存ライブラリは増やさない（Python 標準ライブラリと SQLite のみ）
- 画面は日本語。コマンドを打たなくても操作できること
