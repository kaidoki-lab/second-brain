## 2. 何を作ったか

`fx_bot/` を新しく作った。Python 標準ライブラリだけで動く（MT5 とつなぐときだけ `MetaTrader5` パッケージを使う）。

```
MT5 から過去データ → バックテスト / 期間外検証 → デモ口座で自動売買 → （十分確かめてから）少額の実弾
```

| 段階 | コマンド | 中身 |
| --- | --- | --- |
| データ | `fetch` / `mt5_fetch.bat` | MT5 から確定足を `data/<銘柄>_<時間足>.csv` に保存。MT5 のエクスポート形式の CSV もそのまま読める |
| 検証 | `backtest` | 1つの設定で成績を出す（損益率・最大DD・勝率・PF・連敗など）。取引履歴は CSV に保存できる |
| 選定 | `optimize` | パラメータを総当たりし、前半7割で選んで残り3割で**期間外検証**。過去に合わせ込みすぎた設定を見抜く |
| 運用 | `live` / `mt5_demo.bat` | 足が確定するたびに判断して成行で発注。**デモ口座専用**（リアル口座では起動を拒否） |

### シミュレーションの約束事（甘く見積もらないため）

- 足の確定後に判断し、**次の足の始値**で約定（未来の価格は見ない）
- 買いは ask（bid + スプレッド）、売りは bid
- 同じ足で損切りと利確の両方に届いたら**損切り**を採用
- 窓開けで損切りを飛び越えたら、損切り価格ではなく**始値**で約定
- 数量は「損切りに掛かったら資金の1%を失う」量。レバレッジ25倍で頭打ち
- 資金がピークから20%減ったら全決済して停止

### 自動売買（`live`）の安全策

- リアル口座は拒否（`--allow-real` で解除できるが使わない方針）
- 自分の注文にマジックナンバー `210001` を付け、**手動のポジションには触らない**
- 損切り・利確は **MT5 側に注文として置く** → プログラムが止まっても損切りは効く
- 開始後の最高値から有効証拠金が20%減ったら全決済して終了
- 注文エラーはログに出して動き続ける。Ctrl+C で停止（ポジションは残る）
- 起動直後は最新の確定足で判断するので、`ma_cross` はすぐにポジションを持つ

## 3. 確認できていないこと（要注意）

1. **本物の MT5 では一度も動かしていない。** クラウド環境には MT5 も Windows もないため、
   `MetaTrader5` パッケージと同じ形で応答する偽のモジュールで確認しただけ。
2. **`.bat` 3つは Windows で実行していない。**
3. **`pip install MetaTrader5` が通るか未確認。** その Python のバージョンにまだ対応していないと失敗する。
   そのときは対応している Python を入れる（PyPI の MetaTrader5 のページで確認）。
4. **業者ごとの違い**: 銘柄名（`USDJPY-` / `USDJPY.m` など）、1ロットの通貨量、約定方式（FOK/IOC）は
   MT5 から読み取って合わせているが、実際の業者で確かめていない。
5. MT5 の「アルゴリズム取引」がオフだと注文が通らない（エラー 10027 になるはず）。
6. **`update.bat` では反映されない。** `update.ps1` は main の ZIP しか取らず、入れ替え対象も
   `second_brain` と `SOT21_Controller` だけ。`fx_bot/` は独立させたので対象に入れていない。
7. 実データでの成績はまだ誰も見ていない。合成データ（`sample`）の成績には意味がない。
8. スワップ・スリッページ・約定拒否はバックテストに入っていない。

## 5. 守っている設計の約束（変えないこと）

- **リアル口座では既定で動かさない。** デモで十分確かめるまで実弾は使わない
- 手動のポジションには触らない（マジックナンバーで区別）
- 損切りは必ず MT5 側に置く。損切りのない注文は出さない
- 戦略は方向と損切り幅を返すだけで、発注しない。バックテストと live は同じ `step()` を通る
- 未来の価格を見ない（判断は確定足、約定は次の足）
- 依存ライブラリは増やさない（標準ライブラリのみ。MT5 連携時だけ `MetaTrader5`）
- second_brain / SOT21 とは連携しない独立ツール
- 表示は日本語。ダブルクリックで動かせること
- 利益を保証するものではない。投資判断と損失はユーザー自身の責任
